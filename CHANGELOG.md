### BREAKING CHANGES

* the package is now @cairn-tool/cairn. tool.name in the
envelope and generator.name in every report Cairn writes report the new name,
schema $ids are rooted at https://github.com/cairn-tool/cairn/schema, and the
contract schemaVersion is 3. The v1 segment of every schema id is unchanged --
no payload shape changed -- and the short ids `cairn schema <id>` takes are
unchanged. @bstockus/cairn is not updated past v1.11.0.
* `usage index` now reports on the SQLite store rather than the
JSON shard cache. Three fields change meaning and are recorded in the contract
registry rather than removed: `shards` is always 0, because the per-project shard
files it counted no longer exist; `removed` counts transcripts dropped by
--clear rather than shard files deleted; and `bytes` is the whole store's size,
reported identically on every `caches` entry rather than partitioned, so it is
not summed. `entries` keeps its meaning. The scan cache under XDG_CACHE_HOME is
no longer read or written and can be deleted.
* the npm package is @bstockus/cairn and the binary is `cairn`.
CONTRACT_VERSION is 2: schema $id values are rooted at
https://github.com/bstockus/cairn/schema (the v1 major segment and the short
schema ids are unchanged, as no payload shape changed), describe reports
machineStreams.optOutEnv as CAIRN_NO_UPDATE_NOTIFIER, and tool.name in the
envelope and describe payloads is @bstockus/cairn. Shell completion scripts must
be regenerated. Cache directories moved to ~/.cache/cairn and rebuild on demand.
